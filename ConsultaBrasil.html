🇧🇷 Consulta Brasil

APIs públicas oficiais integradas — CEP, CNPJ, Processos (DataJud), Taxas, FIPE, PIX e mais.

Consultar CEP

ViaCEP + BrasilAPI (v1/v2) em paralelo + enriquecimento IBGE e DDD.

Endereço → CEP

ViaCEP. Clique em um resultado para enriquecer com dados completos.

Consultar CNPJ

BrasilAPI (Receita). Após a consulta, o CEP da empresa é enriquecido automaticamente.

Processos Judiciais (DataJud / CNJ)

API Pública oficial do CNJ. Consulta por número único do processo. Dados de capas e movimentações públicas. Processos sigilosos e dados sensíveis de partes são protegidos pela própria API.

Consultar DDD

BrasilAPI — estados e cidades cobertas pelo código de área.

Bancos

BrasilAPI — lista completa ou busca por código COMPE.

Taxas oficiais

BrasilAPI — Selic, CDI, IPCA e outras taxas de referência.

Tabela FIPE

BrasilAPI — marcas e veículos. Selecione o tipo, depois a marca.

Participantes do PIX

BrasilAPI — instituições participantes do sistema PIX (Banco Central).

Feriados Nacionais

BrasilAPI.

Corretoras (CVM)

BrasilAPI — corretoras registradas na CVM. Lista ou busca por CNPJ.

Fontes públicas: ViaCEP · BrasilAPI · DataJud/CNJ. Uso apenas para consulta. Dados de processos sigilosos e partes sensíveis são protegidos pela própria API do CNJ.
